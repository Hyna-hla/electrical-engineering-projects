# 电能质量在线监测与谐波分析系统

> 团队课程设计项目 | 面向电气工程专业

## 一、项目简介

针对配电母线谐波污染问题，团队开发了电能质量监测与分析系统，实现信号采集仿真、
**加窗插值 FFT 谐波分析**、**GB/T 14549-1993 国标自动判定**、24 小时趋势监测与
超标告警的全流程，为谐波治理（加装 APF/SVG）提供数据依据。

**核心指标（算法自验证）：**
- 基波频率测量误差 < 0.05 Hz（电网频率偏差 49.8 Hz 工况下）
- 谐波幅值测量误差 < 0.5%，THD 测量误差 < 0.02 个百分点
- 单次分析（10 周波 × 128 点）耗时 < 10 ms，满足在线监测实时性要求

## 二、功能特性

| 模块 | 功能 |
|------|------|
| 信号采集 | 模拟 10 kV 母线电压信号：基波频率偏差（49.8 Hz）、3~13 次特征谐波、噪声、负荷波动 |
| 频率估计 | 汉宁窗 FFT + 对数谱抛物线插值，精确锁定实际基波频率 |
| 谐波分析 | 软件准同步重采样（整周期采样）+ FFT，各次谐波幅值/相位高精度提取 |
| 国标判定 | THD 与奇次谐波含有率按 GB/T 14549-1993 限值自动判定，输出越限明细 |
| 趋势监测 | 24 小时 THD 趋势、超标时段统计、负荷-THD 相关性分析、治理建议 |

## 三、技术栈

`Python 3` + `NumPy/SciPy`（FFT、样条重采样）+ `Matplotlib`（可视化）

## 五、运行方法

```bash
cd src
python main.py
```

## 六、运行结果（摘要）

- 基波频率测量 49.784 Hz（真实 49.800 Hz），幅值测量误差 0.01%
- 谐波含有率实测与设定值对照：3 次 1.79%/1.80%，5 次 3.58%/3.60%，7 次 2.22%/2.20%
- **判定结论：THD = 4.89% 超出国标限值 4%，5 次谐波 3.58% 超过奇次限值 3.2%**
- 24 小时监测显示 THD 随负荷波动，早/晚高峰超标（与负荷相关系数见结果图 4）
- 治理建议：晚高峰时段投运 APF 有源滤波，优先抑制 5、7 次谐波
