# 电能质量谐波分析

模拟 10kV 母线电压的谐波监测分析。被分析信号是自己仿真的（基波 49.8Hz 带频率偏差、3~13 次特征谐波、噪声、日负荷波动），但分析部分按真实监测装置的思路写，以后接实际采集数据时把 signal_source.py 换掉就行，接口不变。

## 为什么要加窗插值

直接做 FFT 的问题：电网频率不是刚好 50Hz 时谱线对不准频点，频谱泄漏会让幅值差很远。最开始就是直接取谱线峰值，在 49.8Hz 工况下基波幅值测出来只有真实值的一半，谐波含有率整体偏高将近一倍。

现在的流程分三步：

1. 汉宁窗 FFT，在对数谱上抛物线插值，先把实际基波频率测准；
2. 按测到的频率对信号做三次样条重采样，凑成整周期采样（每周波 128 点、取 8 个周波）；
3. 整周期 FFT，各次谐波正好落在谱线上，幅值相位不用再修正。

改完之后用设定值反推测量误差：基波幅值误差 0.01%，谐波含有率误差不到 0.02 个百分点，THD 测量值 4.89% 对理论值 4.90%。

## 国标判定

按 GB/T 14549-1993 判：10kV 电网 THD 限值 4%，奇次谐波含有率限值 3.2%，偶次 1.6%。当前仿真的工况 THD 4.89%、5 次谐波 3.58%，都是超标的，报告里的建议是加装有源滤波器优先滤 5、7 次。

另外做了 24 小时的 THD 趋势监测：谐波源幅值跟着日负荷走，早晚高峰超标，负荷-THD 相关性画在图 4 里。

## 运行

```bash
cd src && python main.py
```

signal_source.py 是信号仿真和日负荷曲线，analyzer.py 是频率估计、重采样、谐波分析和国标判定，main.py 串起来出报告和四张图。
