# 智能家居环境监测系统（嵌入式节点 + 上位机）

> 5 人团队大创/课程设计项目 | 面向电气/自动化/物联网方向

## 一、项目简介

团队开发了"多传感节点 + 上位机监控"的室内环境监测系统：STM32 节点周期采集
温湿度（DHT11）、光照（BH1750）、烟雾（MQ-2），按自定义串口协议上报；
上位机完成帧解析（CRC 校验）、越限告警、CSV 记录与趋势分析。

**本项目最大特点是软硬件协同 + 团队分工明确**：嵌入式组与上位机组通过
**联合评审的通信协议文档**实现并行开发，最终联调一次通过。

**运行验证（24 小时仿真数据）：**
- 1440 帧数据，注入 0.5% 随机误码，CRC 全部正确拦截（8 帧），有效率 99.4%
- 消防演练烟雾事件（14:10~14:35）触发了 11 次烟雾告警，无漏报
- 电池电压监测 3900 → 3600 mV 趋势正常

## 二、系统架构

```
[DHT11 温湿度] ─┐
[BH1750 光照 ] ─┼─ STM32F103 节点 ──UART 115200──>  Python 上位机
[MQ-2 烟雾  ] ─┘   (采集/判限/打包/CRC)            (解析/告警/记录/可视化)
```

## 三、功能特性

| 端 | 模块 | 功能 |
|----|------|------|
| 固件 | 传感器驱动 | DHT11 单总线时序（40bit + 校验和）、BH1750 I2C、MQ-2 ADC 中值滤波 |
| 固件 | 协议层 | 帧打包 + CRC8；环境帧周期上报 + 越限告警帧立即上报 |
| 上位机 | 解析引擎 | 字节流状态机（容忍粘包/分包/噪声）+ CRC 校验 |
| 上位机 | 监控功能 | 五类越限告警、CSV 记录、温湿度/光照/烟雾/电池四类趋势图 |
| 上位机 | 数据源 | 无硬件时可接仿真数据源演示（SerialSimSource），有硬件换 pyserial 即可 |

## 四、目录结构

```
05-智能家居环境监测系统/
├── firmware/                  # STM32 端 (参考实现, Keil/CubeIDE 编译)
│   ├── protocol.h / protocol.c        # 帧打包 + CRC8 (与上位机逐字节兼容)
│   ├── sensor_drivers.h / sensor_drivers.c  # DHT11/BH1750/MQ-2 驱动
│   └── main.c                         # 主循环调度 + 越限判定 + 上报
├── host/                      # Python 上位机 (可直接运行)
│   ├── protocol.py            # CRC8 + 帧解析状态机
│   ├── simulator.py           # 串口仿真数据源 (含误码注入)
│   ├── monitor.py             # 监控主程序
│   └── verify.py              # 协议自验证 (CRC 标准向量/误码/分包)
├── docs/通信协议文档.md       # 跨组协作的核心约定
├── results/                   # CSV + 报告 + 4 张图
└── README.md
```

## 五、运行方法

```bash
cd host
python monitor.py        # 使用仿真数据源 (无需硬件)
python verify.py         # 协议自验证 (CRC 标准向量 / 往返一致 / 误码拦截 / 分包)
```
接入真实节点时，将 `monitor.py` 中的 `SerialSimSource` 替换为 `pyserial`
串口对象（接口同为 `read_chunk()/finished`），其余代码零改动。
