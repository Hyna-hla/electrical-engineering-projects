# 上下位机通信协议 V1.0

> 由嵌入式组与上位机组联合评审确定。**协议先行**：双方冻结本文档后再并行开发，
> 是本项目跨组协作的关键约定。

## 1. 物理层

- 接口：UART，115200 bps，8-N-1
- 电平：TTL 3.3V（上位机侧经 USB转TTL 模块）

## 2. 帧格式（小端序）

| 字段 | 长度 | 说明 |
|------|:---:|------|
| 帧头 | 2 | 0xAA 0x55 |
| LEN | 1 | 载荷长度（0~255） |
| TYPE | 1 | 帧类型 |
| PAYLOAD | LEN | 载荷 |
| CRC8 | 1 | 校验范围：**LEN + TYPE + PAYLOAD** |
| 帧尾 | 1 | 0x0D |

## 3. CRC8 参数

- 多项式：0x07（x⁸+x²+x+1）
- 初值：0x00；无输入/输出反转；无异或输出
- 固件（`firmware/protocol.c`）与上位机（`host/protocol.py`）实现逐字节一致，
  联调时以已知向量交叉验证

## 4. 帧类型定义

### 4.1 TYPE=0x01 环境数据帧（节点 → 上位机，1 帧/分钟）

| 字段 | 类型 | 说明 |
|------|------|------|
| node_id | u8 | 节点编号 |
| temp_x10 | i16 | 温度 ×10（0.1 °C 分辨率） |
| humi_x10 | u16 | 湿度 ×10（0.1 %RH） |
| lux | u16 | 光照（lux） |
| smoke_adc | u16 | MQ-2 原始 ADC 值（12bit） |
| batt_mv | u16 | 电池电压（mV） |

### 4.2 TYPE=0x02 告警帧（节点 → 上位机，越限立即上报）

| 字段 | 类型 | 说明 |
|------|------|------|
| node_id | u8 | 节点编号 |
| alarm_code | u8 | 0x01 烟雾 / 0x02 高温 / 0x03 低温 / 0x04 高湿 / 0x05 低湿 |

### 4.3 TYPE=0x03 应答帧（上位机 → 节点）

| 字段 | 类型 | 说明 |
|------|------|------|
| node_id | u8 | 目标节点 |
| ack_seq | u8 | 应答序号（保留） |

## 5. 容错约定

- 上位机解析必须容忍**粘包/分包/噪声字节**（状态机逐字节扫描帧头）
- CRC 校验失败：丢弃该帧并计入误码统计，**不**尝试重同步到帧尾
- 节点侧传感器读取失败：发送载荷全 0xFF 的环境帧，上位机按缺测处理
