# 直流电机 PID 调速仿真

24V 直流电机的转速闭环仿真。做这个主要是想把几件事亲手验证一遍：P、PI、PID 到底差在哪，积分饱和是怎么回事，参数整定时快速和平稳怎么权衡。

## 模型和控制器

电机是他励直流机，电枢回路方程加机械方程，两个状态（电枢电流、转速），RK4 定步长积分，步长 0.1ms。控制周期 1ms，控制量在一个周期内保持不变，相当于 PWM。参数按典型 200W 电机取的。

控制器是位置式数字 PID，写了三个工程上常用的处理：积分抗饱和（clamping，输出受限且误差同号时冻结积分）、微分先行（对转速测量值微分，给定值阶跃时控制量不会打出去）、微分项一阶低通。

## 一个调试中碰到的坑

一开始用阶跃给定，发现怎么加 Kd 超调都不降反升，和教科书结论相反。查下来是起动阶段控制量深度饱和（误差乘 Kp 远超 24V 上限），抗饱和逻辑和微分项相互作用导致的。改成斜坡软起动（1 秒升到 1500rpm）后系统基本工作在线性区，规律就正常了。真实系统里斜坡给定本身也是常规做法。

## 对比结果

工况是 1500rpm 斜坡给定，第 4 秒突加 0.4 N·m 负载：

- 纯 P（Kp=0.6）：稳态误差 243rpm 消不掉，负载一加直接掉 243rpm
- PI（Kp=0.6, Ki=8）：超调 4.3%，扰动速降 20rpm
- PID（Kp=1.2, Ki=16, Kd=0.05）：超调 4.1%，扰动速降 9rpm

微分项的价值不在降超调（这个对象上作用有限），而在允许把 Kp、Ki 抬高一倍——抗扰能力翻了一倍多，超调没有变差。

另外做了 Kp 扫描（图 3）。比较意外的结果是这个系统里超调随 Kp 增大反而减小：起动阶段执行器饱和的前提下，更大的 Kp 让系统更早脱离饱和区，配合抗饱和把超调压住了；调节时间在 Kp≈0.8 附近最优。
