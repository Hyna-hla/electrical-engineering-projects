# 直流电机 PID 调速系统仿真平台

> 团队课程设计项目 | 面向电气/自动化专业

## 一、项目简介

直流电机转速闭环控制是运动控制的基础课题。团队建立了**他励直流电机的机电暂态模型**
（电枢回路 + 机械运动方程，RK4 数值积分），实现了带**积分抗饱和、微分先行、微分
低通滤波**三项工程化处理的数字 PID 控制器，通过参数整定对比实验量化了 P/PI/PID
的控制性能差异，并分析 Kp 参数的快速性-平稳性权衡。

**核心结果（1500 rpm 斜坡给定，4 s 突加 0.4 N·m 负载）：**

| 控制器 | 超调 σ% | 稳态误差 | 负载扰动最大速降 |
|--------|:---:|:---:|:---:|
| 纯 P (Kp=0.6) | 0% | 243 rpm（无法消除） | 243 rpm |
| PI (Kp=0.6, Ki=8) | 4.3% | ≈0 | 20 rpm |
| PID (Kp=1.2, Ki=16, Kd=0.05) | **4.1%** | ≈0 | **9 rpm（↓55%）** |

结论：积分项消除稳态误差；微分项支撑更高增益，在不增大超调的前提下将抗扰能力
提升 55% 以上。

## 二、功能特性

| 模块 | 功能 |
|------|------|
| 电机建模 | 电枢电压方程 + 机械方程联立，RK4 定步长积分（dt=0.1 ms），模拟 PWM 保持 |
| 控制器 | 数字位置式 PID，含积分抗饱和（clamping）、微分先行、微分一阶低通滤波 |
| 工况脚本 | 斜坡软起动给定、负载转矩阶跃（模拟切削/传送带加载） |
| 指标体系 | 超调量/上升时间/调节时间/稳态误差/扰动最大速降自动计算 |
| 参数分析 | Kp 扫描的超调-调节时间权衡曲线 |

## 六、运行结果（摘要）

- 纯 P 控制：存在 243 rpm 稳态误差且负载扰动速降达 243 rpm，验证"比例控制无法
  消除稳态误差"
- PI 控制：稳态误差归零，超调 4.3%，扰动速降 20 rpm
- 高增益 PID：借助微分阻尼将 Kp/Kp 提高一倍，扰动速降降至 9 rpm，超调反而略降
- Kp 扫描显示调节时间随 Kp 先降后升，在 Kp≈0.8 处最优；超调随 Kp 增大不升反降
  ——因为本系统起动阶段执行器深度饱和，更大的 Kp 反而使系统更早脱离饱和区，
  配合抗积分饱和抑制了超调（饱和受限系统的典型特性，见
  `results/3_Kp参数权衡分析.png`）
