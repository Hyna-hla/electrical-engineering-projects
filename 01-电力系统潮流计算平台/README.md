# 电力系统潮流计算平台

牛顿-拉夫逊法潮流计算程序，算例是 IEEE 14 节点标准系统，数据按 Matpower 的 case14 录入（含三台变压器的非标准变比、9 号节点并联电容）。

## 算法

极坐标形式的功率方程，修正方程的雅可比矩阵按 H、N、J、L 四个子块装配，每次迭代重新形成、直接求解，没有做 PQ 分解简化。变压器支路用 π 型等值处理变比，线路充电容纳按全线总容纳每端计一半。

平启动（V=1.0、θ=0）5 次迭代收敛到最大功率不平衡量 1e-8，14 节点规模下耗时 3ms 左右，收敛曲线能看到典型的不平衡量逐次平方下降。

## 结果

main.py 跑完会在控制台打印节点电压/相角、支路潮流，results 下另有 4 张图和一份文本报告：网络潮流分布图（线宽对应传输功率）、节点电压柱状图（标了 0.95~1.05 合格区间）、收敛特性、网损前十的支路。

几个数字：全网网损 13.39 MW，占总发电 4.92%，最大的支路是 1-2；14 个节点电压都在合格区间内，最低的是 14 号节点 1.0355 pu。

## 结果校验

verify.py 做三件事，跑一遍就知道算得对不对：

1. 解析雅可比和有限差分数值求导逐元素对比（当前最大偏差 4e-6）；
2. 全网功率平衡：发电减负荷减网损，残差应为零；
3. 和 Matpower 官方发布的 case14 解逐节点对比。

第三项目前电压最大偏差 0.13%，相角 0.017°，平衡机出力 232.4 MW 对 232.4 MW。

## 运行

```bash
cd src
python main.py
python verify.py
```

## 文件说明

network_data.py 是算例数据，和算法完全解耦，换一套节点/支路参数就能算别的系统；solver.py 是导纳矩阵形成、NR 迭代和支路潮流计算；visualize.py 只管画图；main.py 和 verify.py 是两个入口。
