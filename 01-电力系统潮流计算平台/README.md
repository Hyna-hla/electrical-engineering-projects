# 电力系统潮流计算与可视化分析平台

> 团队课程设计项目 | 面向电气工程专业

## 一、项目简介

针对电力系统规划与运行分析中最基础的潮流计算问题，团队基于 Python 自主开发了
**牛顿-拉夫逊法潮流计算引擎**，以国际通用的 **IEEE 14 节点标准算例**为对象，
实现从网络建模、迭代求解到结果可视化分析的全流程，并可输出工程应用所需的
电压水平评估、网损分析与降损改造建议。

**核心指标（`src/verify.py` 自验证脚本可一键复现）：**
- 计算引擎 5 次迭代收敛至 1e-8 精度，耗时约 3 ms（14 节点系统）
- 与 Matpower 官方发布的 IEEE 14 节点解对比：电压最大偏差 0.13%、相角 0.017°、
  平衡机功率 232.4 vs 232.4 MW
- 三项独立校验：雅可比矩阵 vs 有限差分数值求导（<1e-5）、全网功率平衡
  （残差 <0.001 MW）、与官方解逐节点对比
- 支持任意规模网络扩展（数据驱动，节点/支路数据与算法完全解耦）

## 二、功能特性

| 模块 | 功能 |
|------|------|
| 网络建模 | 节点导纳矩阵自动形成，支持线路 π 型等值、变压器非标准变比、并联电容 |
| 潮流求解 | 牛顿-拉夫逊法（极坐标形式），H/N/J/L 四子块雅可比矩阵，平启动 |
| 结果校验 | verify.py：雅可比 vs 有限差分（<1e-5）、功率平衡（残差≈0）、与 Matpower 官方解逐节点对比 |
| 工程分析 | 节点电压越限判定（0.95~1.05 pu）、支路潮流分布、网损排行与降损建议 |
| 可视化 | 网络潮流分布图、电压水平柱状图、迭代收敛特性曲线、网损 Top10 排行 |

## 三、技术栈

`Python 3` + `NumPy`（矩阵运算）+ `Matplotlib`（可视化）

## 四、目录结构

```
01-电力系统潮流计算平台/
├── src/
│   ├── network_data.py   # IEEE 14 节点标准算例数据（数据与算法解耦）
│   ├── solver.py         # NR 求解器：导纳矩阵 / 雅可比 / 迭代 / 支路潮流
│   ├── visualize.py      # 4 类分析图
│   ├── main.py           # 主程序入口
│   └── verify.py         # 自验证：雅可比/功率平衡/官方解对比
├── results/              # 运行输出：潮流计算报告.txt + 4 张分析图
└── README.md
```

## 五、运行方法

```bash
cd src
python main.py      # 潮流计算 + 报告与 4 张分析图
python verify.py    # 三项自校验 (雅可比 / 功率平衡 / Matpower 官方解对比)
```

## 六、运行结果（摘要）

- **收敛性**：平启动下 5 次迭代即收敛，最大功率不平衡量呈典型二次下降（见 `results/3_收敛特性曲线.png`）
- **电压水平**：14 个节点全部落在 0.95~1.05 pu 合格区间，最低电压节点 14（1.0355 pu，
  与 Matpower 官方解 1.036 一致）
- **网损**：全网总有功损耗 13.39 MW，占发电量 4.92%；网损最大支路为 1-2（见网损排行图）
- **平衡节点**：系统需要从 1 号节点吸入 232.4 MW 有功，与 Matpower 官方解一致
