# electrical-engineering-projects

几个电气工程方向的项目，覆盖潮流计算、电能质量、光伏发电、电机控制、嵌入式监测，都是能直接跑起来的。代码在各项目的 src 里（项目 5 是 firmware 加 host），跑出来的图表和报告在 results 里。

环境：Python 3.8 以上，需要 numpy、scipy、matplotlib。

```bash
pip install -r requirements.txt

# 以项目 1 为例
cd 01-电力系统潮流计算平台/src
python main.py
python verify.py
```

项目 1、3、5 各带一个 verify.py，是对计算结果本身的校验，比如潮流的结果逐节点和 Matpower 官方解对比、光伏模型 STC 参数和组件手册对比、CRC 用标准测试向量核对，跑一下就能确认程序算得对不对。

## 项目列表

- 01 电力系统潮流计算平台：牛顿-拉夫逊法解 IEEE 14 节点标准算例。雅可比按 H/N/J/L 四子块装配，平启动 5 次迭代收敛到 1e-8；结果和 Matpower 官方解对比电压偏差 0.13% 以内。附网络潮流分布图、电压越限检查、网损排行。

- 02 电能质量谐波分析：加窗插值 FFT 加准同步重采样做谐波测量，解决电网频率偏离 50Hz 时的频谱泄漏问题（直接 FFT 幅值能差一半），谐波测量误差压到 0.5% 以内，按 GB/T 14549-1993 判定越限，另有 24 小时 THD 趋势监测。

- 03 光伏 MPPT 控制仿真：单二极管光伏模型（STC 参数对标组件手册），定步长/变步长扰动观察法和电导增量法放在一起跑同样的光照阶跃工况，追踪效率、稳态振荡、动态响应的差别一目了然。

- 04 直流电机 PID 调速：电机机电模型 RK4 积分，带抗饱和、微分先行的数字 PID。记录了一个有意思的现象：起动深度饱和时加 Kd 超调反而变大，改成斜坡软起动后教科书规律才成立。

- 05 智能家居环境监测：STM32 传感器驱动（DHT11/BH1750/MQ-2）加 Python 上位机，自定义串口协议带 CRC8，解析用字节流状态机。24 小时仿真数据 1440 帧，注入的误码全部拦截，烟雾事件告警无漏报。
