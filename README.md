# 电气工程项目集 Electrical Engineering Projects

5 个可完整运行的电气工程专业项目，覆盖**电力系统分析、电能质量、新能源发电、运动控制、嵌入式物联网**五个方向。所有项目均基于 Python 实现（项目 5 含 STM32 嵌入式固件参考实现），结果可一键复现，关键算法配有独立自验证脚本。

## 项目一览

| # | 项目 | 方向 | 核心技术 |
|---|------|------|----------|
| 01 | [电力系统潮流计算平台](01-电力系统潮流计算平台/) | 电力系统 | 牛顿-拉夫逊法、雅可比矩阵、IEEE 14 节点标准算例、变压器 π 型等值 |
| 02 | [电能质量谐波分析系统](02-电能质量谐波分析系统/) | 电能质量 | 加窗插值 FFT、准同步重采样、GB/T 14549 国标判定 |
| 03 | [光伏 MPPT 控制仿真](03-光伏MPPT控制仿真/) | 新能源 | 单二极管光伏模型、扰动观察法（定/变步长）、电导增量法 |
| 04 | [直流电机 PID 调速仿真](04-电机PID调速仿真/) | 运动控制 | 机电暂态建模（RK4）、数字 PID、积分抗饱和、参数整定 |
| 05 | [智能家居环境监测系统](05-智能家居环境监测系统/) | 嵌入式/物联网 | STM32 传感器驱动、串口协议设计、CRC8 校验、上位机解析状态机 |

## 运行方法

环境要求：Python 3.8+，`numpy` `scipy` `matplotlib`（项目 1~4），项目 5 需 `numpy` + `matplotlib`。

```bash
# 各项目 (项目 5 在 host 目录)
cd 01-电力系统潮流计算平台/src && python main.py

# 项目 1/3/5 附带自验证脚本
python verify.py
```

## 自验证结果

| 项目 | 验证方式 | 结果 |
|------|---------|------|
| 01 潮流计算 | `verify.py`：雅可比 vs 有限差分、全网功率平衡、与 Matpower 官方解逐节点对比 | 电压偏差 <0.13%、相角 <0.02°、功率平衡残差 ≈ 0 |
| 02 谐波分析 | 仿真信号已知真值反推测量误差 | 基波幅值误差 0.01%，谐波含有率误差 <0.02 个百分点 |
| 03 光伏 MPPT | `verify.py`：STC 参数对标组件手册、温度/光照物理规律、I-V 单调性 | Vmp=263.4 V / Imp=7.59 A / Pmp=2000 W |
| 04 PID 调速 | P/PI/PID 对照实验 + 指标自动计算 | 高增益 PID 扰动速降 9 rpm（PI 为 20 rpm），超调 4.1% |
| 05 环境监测 | `verify.py`：CRC-8 标准测试向量、误码注入、分包测试 | 24h 共 1440 帧，8 帧注入误码全部拦截，告警零漏报 |

## 目录说明

每个项目包含：

- `src/`（项目 5 为 `firmware/` + `host/`）—— 全部源码

- `README.md` —— 项目背景、算法原理、运行结果与目录结构
