# 光伏 MPPT 控制仿真

光伏电池的输出特性随光照温度变化，工作点不跟踪的话功率损失很快，所以做了这个单二极管模型加三种 MPPT 算法的对比仿真。组串按 10 块 200W 多晶硅组件串联，STC 下 2kW。

## 光伏模型

单二极管方程 I = Iph − I0(exp((V+IRs)/a) − 1) − (V+IRs)/Rsh，是电流的隐式方程，用牛顿迭代解。光照和温度的修正都做了：Iph 随光照线性、随温度加 Isc 温度系数，I0 按硅带隙做指数修正。

verify.py 里对模型做过校验，STC 下 Vmp=263.4V、Imp=7.59A、Pmp=2000W，和组件手册参数对得上；600 W/m² 时功率约为额定 0.59 倍、55°C 高温下功率降 13%、Vmp 降 13%，物理规律都对。

## 三种 MPPT 算法

定步长扰动观察、变步长扰动观察、电导增量法各写了一个，统一接口（update(v, i) 返回电压参考），要加别的算法继承 BaseMPPT 就行。Boost 那一侧没有细建开关级模型，用一阶惯性环节模拟电压环跟踪，时间常数 0.01s，远小于 0.05s 的控制周期。

仿真工况：光照 1000→600→800 W/m² 三段阶跃（模拟云遮挡），温度 45→40→38°C 分段。

对比结果（main.py 会打印并画图）：

- 平均追踪效率三种都超过 99.7%，差别不大
- 稳态振荡差别明显：定步长 ±1.3W，INC ±0.6W，变步长收敛后基本不动
- 光照阶跃瞬间都掉到 90% 上下，半秒内拉回新工作点

变步长的思路是步长乘 |ΔP/ΔV|，离 MPP 远时斜率大步长就大，到顶上斜率趋零步长自动收缩。综合看变步长 P&O 最均衡。
