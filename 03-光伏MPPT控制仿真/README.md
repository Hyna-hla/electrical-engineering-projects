# 光伏发电 MPPT 控制算法仿真对比平台

> 4~团队课程设计项目 | 面向电气工程专业

## 一、项目简介

光伏电池的输出特性随光照、温度强非线性变化，必须实时调整工作点才能始终输出
最大功率（MPPT）。团队建立了**光伏阵列单二极管物理模型**与 Boost 变换器电压环
动态模型，在同一仿真平台上对**定步长扰动观察法（P&O）、变步长 P&O、电导增量法
（INC）**三种主流 MPPT 算法进行横向对比，从追踪效率、稳态振荡、动态响应三个维度
量化评估，为算法选型提供依据。

**核心结果：**

| 算法 | 平均追踪效率 | 稳态功率振荡 | 特点 |
|------|:---:|:---:|------|
| 定步长 P&O | 99.74% | ±1.3 W | 实现最简单，稳态有振荡 |
| 变步长 P&O | **99.75%** | **±0.0 W** | 兼顾快响应与低振荡，推荐 |
| 电导增量 INC | 99.71% | ±0.6 W | 判据严谨，对采样噪声敏感 |

工况：2 kW 组串，光照阶跃 1000→600→800 W/m²（模拟云遮挡），温度 45→40→38 °C。

## 二、功能特性

| 模块 | 功能 |
|------|------|
| 光伏建模 | 单二极管模型（牛顿迭代解隐式方程），光照/温度修正，参数对标 200 W 多晶硅组件（STC 校验：Vmp=263 V，Imp=7.6 A，Pmp=2 kW） |
| 变换器建模 | MPPT 输出电压参考 + 一阶惯性电压环，模拟 Boost 闭环动态 |
| 算法库 | 定步长 P&O / 变步长 P&O / INC，统一接口，便于扩展（模糊控制、黄金分割等） |
| 对比评估 | 追踪效率曲线、稳态振荡峰峰值、阶跃响应跌落深度，自动生成报告 |

## 三、技术栈

`Python 3` + `NumPy`（模型求解）+ `Matplotlib`（可视化）

## 四、目录结构

```
03-光伏MPPT控制仿真/
├── src/
│   ├── pv_model.py   # 光伏单二极管模型 + MPP 扫描求解
│   ├── mppt.py       # 三种 MPPT 算法 (统一接口)
│   └── main.py       # 仿真主程序: 特性曲线 + 算法对比 + 报告
├── results/          # 对比报告 + 4 张图
└── README.md
```

## 五、运行方法

```bash
cd src
python main.py      # 仿真对比 + 报告与图表
python verify.py    # 模型自验证 (STC 参数 / 温度光照响应 / I-V 特性)
```

## 六、运行结果（摘要）

- STC 下模型自校验（verify.py）：Vmp/Imp/Pmp/Isc 与组件手册参数一致（误差 < 2%）
- 光照从 1000 骤降至 600 W/m² 时，三种算法均跌至 ~90% 后在 0.5 s 内重新跟踪
  至新 MPP（见 `results/2_MPPT功率跟踪对比.png`）
- 稳态放大图显示：定步长 P&O 围绕 MPP 持续振荡；变步长 P&O 收敛后锁定不动；
  INC 小幅微调（见 `results/4_稳态振荡放大图.png`）
